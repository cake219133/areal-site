# Ареал

Static page “Студентам — Старт в Ареале”. Site files are at the repository root.

**Live site:** https://cake219133.github.io/areal-site/

Pushes to `main` run [`.github/workflows/pages.yml`](.github/workflows/pages.yml), which publishes this directory with GitHub Actions. Under **Settings → Pages → Source**, choose **GitHub Actions**. The branch alternative is **Deploy from a branch** → `main` / `/ (root)`.
