# Школьникам: фронтенд-срез для вёрстки блока «Возможности»

Статическая копия страницы [https://areal.plweb.site/school/](https://areal.plweb.site/school/) с правкой блока `.offers` («Возможности для будущих специалистов»). Это передача фронтенда, не выгрузка Bitrix: бэкенд, формы и админка сюда не входят.

Превью на GitHub Pages: [https://cake219133.github.io/areal-site/school-fix/school/](https://cake219133.github.io/areal-site/school-fix/school/)

У страницы стоит `noindex, nofollow` (и у корневого `school-fix/index.html`, который только перенаправляет в `school/`). Это превью, его не нужно индексировать. На боевой сайт метатег `noindex` переносить не надо.

## Что изменено

1. В `local/templates/career/assets/js/main/common.js` блок `.offers` переписан. В этой папке файл лежит с суффиксом кэша Bitrix: `local/templates/career/assets/js/main/common.js@1795165951166874.js`.
2. Добавлен `local/templates/career/assets/css/offers-steps.css`. В `school/index.html` он подключён сразу после `index.css`.
3. В `src/` тот же код вынесен отдельным модулем: `src/offers-steps.js` и `src/offers-steps.css`.

Полный diff: [changes.patch](changes.patch). Пути в патче — как в шаблоне Bitrix, без `@…` в имени `common.js`.

## Как ведёт себя блок

С ширины 768px секция занимает экран. Один жест (щелчок колеса, жест тачпада, свайп, стрелка, Page Up/Down, пробел) переключает один шаг. Карточек три, шагов три. На первом и последнем шаге следующий жест в ту же сторону отдаёт страницу обычному скроллу. Поворот карточки — один твин, без остановки посередине.

Текст каждой карточки (подпись, абзац) приходит снизу на 30px и проявляется, кривая `expo.out` (то же ощущение, что `cubic-bezier(.19, 1, .22, 1)`). Кнопка стартует вместе с первой строкой и не ждёт stagger. В шаге у подписи отключён общий `transition: all 500ms` у `.btn`, иначе кнопка визуально догоняет ещё полсекунды. Вся подпись, включая кнопку, заканчивается примерно за 0.5–0.6 с после начала шага. Уход зеркальный. При `prefers-reduced-motion` анимации нет.

Фото не проявляется из прозрачности: opacity всё время 1. Карточка, которой ещё нет в кадре, стоит целиком ниже нижнего края вьюпорта (сдвиг считается по повёрнутому габариту) и выезжает на свою позу с `expo.out`. Назад уезжает туда же, тоже без затухания.

Ниже 768px карточки остаются списком, текст проявляется при прокрутке.

Зазор от повёрнутых фото до заголовка и низа экрана считает скрипт (на 1440 это 40px, на узком экране меньше). Фото при низком экране уменьшается, чтобы шаг помещался в 100vh.

## Панель `?tune=1`

Открывается только если в адресе есть `?tune=1`, например:

[https://cake219133.github.io/areal-site/school-fix/school/?tune=1](https://cake219133.github.io/areal-site/school-fix/school/?tune=1)

Обычный посетитель панель не видит. Слайдеры: длительность карточек, кривая, пауза до следующего шага, длительность / шаг / задержка / сдвиг текста, зазор. Прозрачности у фото нет, отдельного ползунка для неё тоже. Значения пишутся в `localStorage` (`offers-steps-tune-v2`). Кнопки «Скопировать настройки» и «Сброс».

Стартовые значения:

| Параметр | Значение |
| --- | --- |
| cardDuration | 0.9 с, ease `expo.out`, opacity фото всегда 1 |
| stepLock | 0.7 с |
| textDuration | 0.48 с |
| textStagger | 0.04 с (кнопка его не ждёт) |
| textDelay | 0 с |
| textOffset | 30 px |
| gap | 40 px |

## Как перенести в Bitrix

Зависимости уже есть в шаблоне: GSAP и ScrollTrigger из `assets/js/libs.min.js`. Отдельный пакет ставить не нужно.

Дальше один из двух путей, не оба сразу. Двойное подключение повесит два обработчика на колесо.

**Патч.** Из корня шаблона, где лежат `local/` и страница школьников:

```bash
patch -p1 < changes.patch
```

Хунк `common.js` ожидает, что сразу после блока закрепления фильтра (`checkSticky`) идёт `$(document).on('click', '.document-dropdown__btn'`. Если между ними всё ещё старая анимация `.offers`, её нужно убрать и вставить содержимое `src/offers-steps.js` вручную. Ссылку на `offers-steps.css` патч добавляет в сохранённый `school/index.html`; в Bitrix ту же строку ставят в шаблон страницы, после `index.css`:

```html
<link href="<?= SITE_TEMPLATE_PATH ?>/assets/css/offers-steps.css" rel="stylesheet">
```

**Модуль.** Положить `src/offers-steps.css` в `assets/css/offers-steps.css`, подключить его в шаблоне и подключить `src/offers-steps.js` после `libs.min.js`. Старый код `.offers` в `common.js` при этом удалить.

`noindex` из этого превью в боевой шаблон не копировать.
